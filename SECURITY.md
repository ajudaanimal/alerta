# Security Policy

## Supported Versions

Only the latest version of this project is actively supported with updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not open a public issue. Instead, report it by contacting the repository owner directly through GitHub or opening a private security advisory if enabled on your repository.
